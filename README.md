## 📝 Introduction

本项目为农业机器人采摘硬件、视觉算法、智能决策规划算法汇总，内容包括项目软硬件需求介绍，软件环境安装配置，以及各功能模块的所有代码。

| Name             | Description                                                  |
| :--------------- | ------------------------------------------------------------ |
| 1_Controller_pkg | 包含机器人所有硬件本体部分内容，及其多种控制方法。           |
| 2_Vision_pkg     | 包含机器人视觉相关部分内容，如相机标定、目标识别、障碍物识别、三维重建等。 |
| 3_Learning_pkg   | 包含所有智能规划算法，如基于采样的自主规划算法、基于强化学习的规划算法、最新的VLA相关规划算法。 |
